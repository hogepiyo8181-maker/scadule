# スケジュール

色分け・給料計算・まとめて登録ができる、スマホ向けのカレンダーアプリです。

- 月・週・日・一覧の表示（月のカレンダーが基本の画面。月には予定の名前が出て、日付をタップすると時間つきの一覧）
- 文字の大きさを「標準・大きめ・特大」から選べる
- Googleカレンダーなどで書き出したファイル（.zip / .ics）から予定を移せる（「色と種類」→「データの保存」。移した予定はまとめて消すこともできる）
- 予定とタスク、終日の予定、何日も続く予定、メモ、場所（地図で開ける）
- 毎日・毎週・毎月・毎年のくり返し予定（1回だけ直す・消すこともできる）
- 予定の検索、長押しで予定を別の日に移動
- 何色を何の予定にするかを自分で決められる色分け（同じ色の明るめ・暗めも選べる）
- 何日でもまとめて選んで予定を入れられる（曜日や文字入力でも）
- 時給・深夜割増・残業・休憩・祝日・昇給に対応した給料計算（交通費は別に計算）
- 予定をiPhoneの「カレンダー」に書き出して、カレンダーのウィジェットで今日の予定をホーム画面に出せる（「色と種類」→「データの保存」）
- ホーム画面に置けて、電波がなくても開ける

予定や設定は、使っている人のスマホ（ブラウザ）の中だけに保存されます。

# よさこい審査（yosakoi/）

紙の審査用紙を打ち込んで、照合・減点・順位までまとめる集計アプリです。
公開先: https://hogepiyo8181-maker.github.io/scadule/yosakoi/

- 「よさこい審査集計」のExcelをそのまま読み込める（チーム・部・演舞テーマ・審査員・審査項目・減点・打ち込んだ点数）
- 紙と同じ並び（審査員ごと・部ごと）で、〇のついた数字を押して入力。倍率（×2・×4）はアプリが計算
- 1〜3人が同じ紙を別々に打ち込んで突き合わせ（照合）。違うところだけ一覧で出る。別のスマホの入力はファイルで受け渡し
- 減点、総合点、個性点（同点判定）での順位、同順位や3位・4位の同点の注意、上位3チームの発表画面、CSV保存
- 審査用紙をA4で印刷
- 入力のしかたを選べる: 「紙を打ち込む」か「審査員のスマホで」。後者は審査員がQRを読んで自分のスマホで採点し、点数のQRを集計担当がカメラで読み取る（サーバーなし・電波がなくても動く）
- QRの作成・読み取りの部品（qrcode-generator: MIT、jsQR: Apache-2.0）は yosakoi/lib/ に同梱
