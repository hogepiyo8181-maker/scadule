# スケジュール

色分け・給料計算・まとめて登録ができる、スマホ向けのカレンダーアプリです。

- 月・週・日・一覧の表示（月のカレンダーが基本の画面）
- 予定とタスク、終日の予定、何日も続く予定、メモ、場所（地図で開ける）
- 毎日・毎週・毎月・毎年のくり返し予定（1回だけ直す・消すこともできる）
- 予定の検索、長押しで予定を別の日に移動
- 何色を何の予定にするかを自分で決められる色分け
- 何日でもまとめて選んで予定を入れられる（曜日や文字入力でも）
- 時給・深夜割増・残業・休憩・祝日・昇給に対応した給料計算（交通費は別に計算）
- ホーム画面に置けて、電波がなくても開ける

予定や設定は、使っている人のスマホ（ブラウザ）の中だけに保存されます。
